# Git Hook 기반 DevSecOps 보안 게이트웨이

개발자가 커밋/푸시하는 시점에 6개 보안 도구(gitleaks, Bandit, pip-audit, pip-licenses, Trivy, Checkov)를 자동 실행해 
Secret 유출·취약점·라이선스 문제를 사전 차단하는 Git Hook 기반 DevSecOps 파이프라인입니다.


## 👤 담당 역할 (팀장)
- Git Hook 자동화 프레임워크 설계
- 사용자 로컬 환경 연동 및 설치 스크립트 최적화
- 최종 시스템 통합 및 발표

## 🔧 기술 스택
Python, GitHub, Trivy, checkov, gitleaks, Bandit, pipaudit, piplicenses
