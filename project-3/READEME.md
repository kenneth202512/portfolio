# 버그바운티 기반 실전형 모의해킹

HackerOne 플랫폼을 통해 실제 기업(정책상 비공개)의 Bug Bounty 정책과 Scope를 준수하며,
운영 중인 서비스를 대상으로 보안 취약점을 분석한 모의해킹 프로젝트입니다.

## 👤 담당 역할
- Scope assets 파악
- 취약점 유형 조사·분석
- 로직 흐름 및 파라미터 분석
- 보고서 작성
- 발표

## 🔧 기술 스택
Burp Suite, Kali Linux, Chrome DevTools
